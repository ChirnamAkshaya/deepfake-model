## How to Extract the Dataset

1. Download **all archive files**.
2. Keep them in the **same folder**.
3. Right-click **archive.7z.001**.
4. Select **7-Zip → Extract Here**.

After extraction, the **archive folder will be recreated**, containing:

* train
* test
* sample
* model.py
* model.h5

This folder contains the dataset and trained model used for the deepfake detection system.
